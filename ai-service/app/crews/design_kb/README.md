# Design Agent knowledge base

Drop resume design samples here for the Design Agent to choose from.

Supported files:
- `.docx` — usable as fillable templates (placeholders like `{{name}}`, `{{email}}`,
  `{{phone}}`, `{{location}}`, `{{summary}}`, `{{skills}}`, `{{languages}}`, or as
  style references when no placeholders are present)
- `.pdf` — visual inspiration only (listed in the agent prompt; output is always `.docx`)

Built-in style IDs (always available, no files required):
- `classic` — clean traditional headings
- `modern` — stronger name hierarchy, tighter spacing
- `compact` — denser single-column layout for longer profiles

After adding files, restart the AI service so the template list refreshes.
